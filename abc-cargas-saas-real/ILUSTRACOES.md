# Ilustrações da versão 4

Criadas com a ferramenta integrada de geração de imagens. Os arquivos consumidos pela aplicação são `public/assets/vehicles-v4.png` e `public/assets/inspection-guides.png`. O primeiro contém transparência real; o segundo contém seis exemplos de enquadramento em fundo branco. São figuras ilustrativas.

## Prompt do atlas

Use case: stylized-concept. Asset type: one sprite atlas for a light vehicle fleet web app. Input reference: existing vehicles atlas, use only rendering style. Create a new polished atlas exactly 1536x1024, six equal columns and four equal rows, each cell 256x256 with one centered vehicle, straight orthographic top-down, front at top. All silver/white with dark glass, soft 3D illustrative finish matching reference, transparent background, no text, no labels. Distinct model silhouettes in roof, hood and bed, all cars same relative scale, fit each entirely inside its cell. Row1 left-right: Volkswagen Polo, Volkswagen Virtus, Volkswagen Nivus, Volkswagen T-Cross, Fiat Argo, Fiat Cronos. Row2: Fiat Pulse, Fiat Strada single cab with cargo bed, Fiat Toro double cab short bed, Chevrolet Onix hatch, Chevrolet Onix Plus sedan, Chevrolet Tracker SUV. Row3: Chevrolet S10 pickup double cab bed, Toyota Corolla sedan, Toyota Corolla Cross SUV, Toyota Hilux pickup double cab bed, Honda City sedan, Honda HR-V SUV. Row4: Honda Civic sedan, Hyundai HB20 hatch, Hyundai HB20S sedan, Hyundai Creta SUV, Renault Kwid small hatch, Renault Duster SUV. Six columns four rows; no crop, no roads, no gray tiles, no checkerboard baked in, no borders.

Refinamento usado no arquivo final: remove only the gray studio background between all 24 vehicles, create actual transparent alpha background. Keep the vehicles, silhouettes, positions, sizes, six columns four rows and 1536x1024 dimensions unchanged. Preserve subtle shadows if possible but no opaque gray outside vehicles. Transparent background extraction, not a checkerboard image. Do not add/remove cars.

## Prompt dos guias

Use case: stylized-concept. Asset type: one six-panel photo guide atlas for vehicle inspection app. Input reference existing fleet atlas for style only. Make a polished silver Volkswagen Polo hatchback 3D illustration, matching soft detailed 3D miniature style of reference, not photos, white background. Exactly 3 equal columns by 2 equal rows, 1536x1024 canvas, each panel contains one illustration fully centered, generous margins. Row1 left to right: straight front view of car with grille headlights windshield; straight rear view with taillights hatch and rear windshield; left driver side elevation with front pointing left and all four doors outline. Row2: right passenger side elevation with front pointing right; interior dashboard view showing steering wheel at left and instrument cluster with fuel gauge and odometer no readable numbers; close-up of a door with small illustrative scratch to indicate damage details. Clean neutral silver palette, black glass, soft shadows, uniform scale within views, no words, no labels, no borders, no camera icons, no arrows. These are driver photo examples.
